DESCRIPTION  (about 1,700 characters, LinkedIn allows 2,000)
-----------------------------------------------------------------------

VersoRefuerzo is a free, ad-free web app that helps people memorize Bible
verses using spaced repetition, the same science-based technique behind
modern flashcard apps. I designed, built and deployed it end to end as a
non-profit project for the Spanish-speaking Christian community.

How it works: the user types a citation such as "Juan 3:16", the app
fetches and previews the verse text, and the user personalizes the card
with a color, an icon and a private hint. An SM-2 scheduler then decides
which verses to review each day, right before they would be forgotten.

Highlights:
- Five practice modes: classic flashcards with self-grading, first-letter
  recall, word scramble, verse matching and fill in the blank.
- Smart library: user collections plus automatic groups by book, Old and
  New Testament and the Gospels, always in Bible order.
- Live verse preview, multiple Bible versions, daily streaks and progress.
- Spanish and English interface, designed mobile first, accessible, with
  synthesized sound effects.
- Google sign-in with a private library per user.

Engineering:
- Full-stack Next.js 15 and React 19 in TypeScript, Postgres on Neon with
  Drizzle ORM, Firebase Authentication with server-verified session
  cookies.
- Shared, permanent cache of Bible text from API.Bible, so each verse is
  fetched only once for all users.
- Dockerized and deployed on Google Cloud Run behind Firebase Hosting, with
  Cloud Build, Artifact Registry and Secret Manager.
- 180+ automated tests with Vitest and a GitHub Actions pipeline for lint,
  tests, build and type checks.
- Built to run within free cloud tiers.

Try it free at versorefuerzo.web.app
